UI components never mutate geometry. They dispatch intents; services/document.ts clones the document, applies the mutation, records the previous snapshot and swaps the new document in: 

export function commit(mutator: (draft: Design) => void): Design {
  const current = useDesignStore.getState().design;
  const draft = structuredClone(current);
  mutator(draft);
  draft.updatedAt = Date.now();
  draft.rollback = Math.max(0, Math.min(draft.rollback, draft.timeline.length));
  useHistoryStore.getState().record(current);
  useDesignStore.getState().setDesign(draft);
  return draft;
}

Solids are derived, never stored: regenerate(design) replays the active timeline and returns per-body solids plus a status per feature.

TypeScript data model (abridged)

type Design = {
  id: string; name: string; units: 'mm' | 'cm' | 'in';
  components: Component[]; bodies: Body[]; sketches: Sketch[]; features: Feature[];
  parameters: Parameter[]; joints: Joint[]; timeline: TimelineEntry[];
  rollback: number;            // active timeline length
  updatedAt: number;
};

type Component  = { id; name; parentId: string | null; visible: boolean; transform: Vec3; material: string };
type Body       = { id; name; componentId; featureId; visible: boolean; material: string };

type Sketch = {
  id; name; componentId; plane: 'XY' | 'XZ' | 'YZ';
  entities: SketchEntity[];   // line | polyline | rect | circle
  constraints: Constraint[];  // horizontal | vertical | coincident | parallel | perpendicular
  dimensions: Dimension[];    // length | radius | width | height | distance, expression text
};

type Feature =
  | { kind: 'extrude'; sketchId; distance: string; operation: 'new' | 'cut'; bodyId }
  | { kind: 'fillet';  bodyId; radius: string }
  | { kind: 'shell';   bodyId; thickness: string }
  | { kind: 'move';    bodyId; offset: { x: string; y: string; z: string } };
// every feature also carries id, name, componentId, suppressed

type Selection = {
  kind: 'body' | 'face' | 'edge' | 'sketch' | 'sketchEntity' | 'feature' | 'component' | 'parameter' | 'joint' | 'plane';
  id: string; bodyId?: string; subId?: string; label?: string;
  face?: { area: number; normal: Vec3; point: Vec3 };
  edge?: { length: number; start: Vec3; end: Vec3 };
};

Command system — Extrude end to end

  1. Toolbar dispatches startCommand('extrude'); defaults are derived from the current selection (body, sketch, operation, distance).
  2. CommandPanel renders fields from commandFields(): profile sketch, operation (new body / cut), distance (mm). Cut additionally asks for the target body.
  3. Every keystroke runs previewCommand(), which builds the feature on a clone, regenerates, and returns a SolidSpec — the canvas draws it as a translucent preview, and the panel shows ready / warning / error.
  4. buildCommand() validates with Zod (validateStructure) and evaluates expressions (validateValues); field errors are shown inline and block OK.
  5. OK or Enter commits through commitDesign(), which records the undo snapshot, selects the new body and updates Browser, Canvas, Timeline and Properties from the same document.
  6. Esc cancels without touching the document.

A cut extrude re-checks that the profile lies on the target body's plane and inside its face, then adds the profile and its nested loops as holes in the target solid — a real through hole rather than a decal.

How selection stays synchronised

There is one selection source of truth. Canvas picking builds a Selection (with face area/normal or edge length computed from the picked triangle) and writes it to selectionStore; the Browser rows read the same store and highlight by id (a face selection highlights its parent body). Properties renders from the selected object resolved against the current document, so it can never show stale data. Deleting, undoing or rolling back prunes selection entries whose objects disappeared.

Known limits (deliberate)

  • Geometry is a mock prismatic kernel: extrusion, through holes, rounded profile corners, shelled prisms, moves. No NURBS or general booleans.
  • The sketch solver is a simplified projection solver; dimensions on rectangles/circles are exact, line constraints iterative.
  • Saving is per-browser (localStorage); there is no backend, no accounts and no collaboration.
  • Simulation, CAM, PCB, drawings and motion are visible as “coming soon” workspaces only.
